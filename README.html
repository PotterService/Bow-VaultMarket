Public Folder README

Purpose

This is the public Bow Card Vault website folder.

Safe to edit

  • pages/*.html — page text and layout sections.
  • css/styles.css — colors, spacing, mobile layout, cards, buttons.
  • boosterpack/ — put booster pack images here.
  • boosterbox/ — put booster box images here.
  • data/*.json — exported admin controls and fallback data.

Be careful editing

  • js/data.js — loads Creator Vault, Grade Vault, controls, and auto-generates boosters.
  • config.js — live source URLs and paths.

Booster images

Name images like Myth & Mischief Booster Pack.png in boosterpack/ and Myth & Mischief Booster Box.png in boosterbox/.

v7 cart pricing note

The cart now shows Estimated Value and Sale Price for cards/boosters. The email request includes a note that Bow will reach out for final pricing, more details, and an invoice after the order is confirmed. Items marked Contact for Pricing will be finalized by Bow before invoice.

v8 booster status/text note

The booster page wording was simplified. Booster cards now show one clear availability status so a product should not say Available and Out of Stock at the same time.

v9 disabled feature banners

Public pages now show clear messages when Bow disables request features in admin settings. Creator shows print request disabled, Grade shows purchase/ownership disabled, Boosters shows booster requests disabled, Cart shows cart request disabled, and Ownership shows ownership transfer disabled.

v10 share and booster detail pages

Cards and boosters now have Share buttons. Boosters have a public detail page at public/pages/booster.html. Booster details can be edited in admin booster tools and exported in booster-products.json.

v11 card share and print cost

Card detail pages now include Share, Copy Link, and Facebook share buttons. Creator Vault cards use Print Cost instead of Sale Price. Grade Vault cards and boosters continue to use Sale Price.
