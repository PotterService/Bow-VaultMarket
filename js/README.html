public/js README

What files do

  • data.js — loads card data, control files, images, and auto-generates boosters.
  • cart.js — local cart storage.
  • boosters.js — booster page display.
  • booster-builder.js — custom booster card selection.
  • card-detail.js — card detail page.

Layout changes

Most visual changes should be done in HTML and CSS, not JS.
