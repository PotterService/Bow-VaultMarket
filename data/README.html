public/data README

Files

  • market_controls.json — prices, request toggles, emails, card-specific controls.
  • booster-products.json — custom/override booster products.
  • unavailable_print_cards.json — creator cards blocked from print requests.
  • unavailable_booster_packs.json — out-of-stock booster packs.
  • unavailable_booster_boxes.json — out-of-stock booster boxes.
  • creator-cards.local.json and public-cards.local.json — fallback data only.

v3 export note

Do not copy admin/data to update the site. Admin changes are saved in browser storage and must be exported from admin/export.html. Use Write Directly to public/data Folder or download the files and copy them to public/data/.

v5 print override note

If a card is listed in unavailable_print_cards.json but you mark that exact card as Print Allowed in admin, the card-specific admin setting now wins. Export from admin to update market_controls.json and unavailable_print_cards.json.

v6 value and sale price note

Admin now uses Estimated Value and Sale Price. Older requestPrice fields are still read for backward compatibility, but new saves export estimatedValue and salePrice.
