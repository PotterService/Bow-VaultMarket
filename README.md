# Bow Vault Market

Bow Vault Market is the official marketplace connecting Bow Creator Vault and Bow Grade Vault.

The platform allows visitors to browse creator-owned cards, explore graded collectibles, request prints, purchase available items, and discover custom card products.

Features include:

* Creator Vault card browsing
* Grade Vault collectible listings
* Custom print requests
* Booster pack and booster box products
* Card detail pages
* Collection showcases
* Ownership transfer support
* Availability tracking
* Marketplace request system
* Public inventory browsing

Bow Vault Market serves as the bridge between card creation, collection management, grading records, and marketplace availability.
